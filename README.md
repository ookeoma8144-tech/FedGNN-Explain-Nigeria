# FedGNN-Explain 🇳🇬
### Federated Graph Neural Networks for Explainable Fraud Detection

This project implements a privacy-preserving GNN framework tailored for the Nigerian financial ecosystem (OPay, GTBank, PalmPay).

## 🚀 Key Features
- **Federated Learning:** Training across siloed data without violating NDPR privacy laws.
- **GraphSAGE Architecture:** Capturing topological fraud signatures instead of just tabular patterns.
- **Explainable AI (XAI):** Generating attention-based subgraphs for CBN AML compliance reporting.

## 📈 Results
- **+184% Improvement** in Cross-Institution Ring Recall.
- **0.94 AUC-ROC** on imbalanced PaySim data.

## 🛠️ Tech Stack
- PyTorch Geometric (GNNs)
- Streamlit (Dashboard)
- NetworkX (Visualization)
